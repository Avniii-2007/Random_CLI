# Liftly • Smart Workout Tracker

> Think Less. Lift More.

A clean, distraction-free strength and fitness tracking frontend inspired by [Lyfta](https://www.lyfta.app/). Built with React, Vite, and modern CSS.

## Features

- **Live Workout Logger**: Track sets, weights, and reps with interactive steppers and previous performance memory.
- **Smart Rest Timer**: Automated countdown with audio cues on completed sets.
- **Olympic Plate Calculator**: Interactive barbell sleeve visualizer for standard bumper plates (25kg, 20kg, 15kg, 10kg, 5kg, 2.5kg).
- **1-Rep Max (1RM) Estimator**: Scientific strength projections using the Epley formula.
- **Movement Database**: 5,000+ searchable exercises with category filters and step-by-step technique guides.
- **Weight Units**: Seamless toggle between KG and LBS.
- **Audio Feedback**: Subtle Web Audio API chimes with 1-click mute control.

## Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```

## Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Vanilla CSS (Custom design tokens, Cobalt & Charcoal theme)
- **Icons**: Lucide React
- **Celebration Effects**: Canvas-Confetti
